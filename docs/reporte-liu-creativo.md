## 6. KONTENDA — PLATAFORMA DE GESTIÓN DE CONTENIDO

### ¿Qué es Kontenda?

Kontenda es la plataforma web interna de Liu Creativo que actúa como **portal centralizado entre la agencia y sus clientes**. Reemplaza el caos de WhatsApp, carpetas de Drive y hojas de cálculo con un sistema unificado de producción y revisión de contenido.

> "Tus clientes aprueban su contenido sin WhatsApps de ida y vuelta. Tú produces. Ellos ven, aprueban y publican — todo en un solo lugar."

**Importante:** Kontenda NO es un SaaS comercializable. Es una herramienta exclusiva de uso interno para los clientes de Liu Creativo.

### Problema que resuelve

| Antes de Kontenda | Con Kontenda |
|---|---|
| Seguimiento en hojas de cálculo | Panel visual en tiempo real |
| Archivos dispersos en Drive | URLs de Drive enlazadas por pieza |
| Interminables hilos de WhatsApp | Chat integrado por pieza |
| "¿Dónde está mi contenido?" | Dashboard con estado exacto |
| "¿Cuántas revisiones me quedan?" | Contador visual de rondas |
| "¿Cuándo me cobran?" | Historial de pagos integrado |

### Roles

**Administrador (equipo Liu Creativo)**
- Gestiona clientes y sus configuraciones
- Crea y sube piezas de contenido
- Asigna formatos, fechas, copies, hashtags
- Registra pagos y gestiona planes
- Ve notificaciones de mensajes de clientes
- Administra guiones e ideas

**Cliente (marcas contratantes)**
- Ve su contenido en calendario (día, semana, mes)
- Aprueba piezas con un clic
- Deja feedback por chat en cada pieza
- Descarga archivos finales (Drive / Frame.io)
- Gestiona su brand kit
- Revisa historial de pagos y próximos cobros

### Flujo de Producción (5 etapas)

```
1. Plan activo       → El plan mensual está configurado
2. En producción     → El equipo está creando el contenido
3. En revisión 🟡    → El cliente puede revisar y comentar
4. Entrega disponible 🟠 → Archivos finales listos (Drive/Frame.io)
5. Aprobado/Publicado 🟢 → Pieza cerrada
```

El cliente puede cambiar estados con un solo clic. Cada pieza tiene un contador de rondas de revisión que descuenta en cada corrección solicitada.

## 7. LIU SERVICES — PLATAFORMA DE GESTIÓN INTERNA DE AGENCIA

### ¿Qué es Liu Services?

Liu Services es la plataforma web interna de Liu Creativo para gestionar la **operación financiera y comercial** de la agencia: costos, activos, servicios, clientes, cotizaciones y simulación de rentabilidad.

Permite conocer el punto de equilibrio real, cotizar con márgenes correctos y llevar el control financiero sin depender de Excel.

### Módulos

| Módulo | Ruta | Función |
|---|---|---|
| **Analytics Dashboard** | `/` | Ventas mensuales, gráficos ingresos vs. gastos, BEP anual, P&L |
| **Finanzas** | `/finances` | Costos fijos/variables, activos fijos con depreciación lineal, tasa BEP |
| **Servicios** | `/services` | Catálogo de servicios con precio, horas estimadas y margen automático |
| **Clientes** | `/clients` | CRM: estado del cliente, historial de cotizaciones, WhatsApp integrado |
| **Cotizaciones** | `/quotes` | Generador de propuestas PDF (numeración automática, IVA 19%, términos) |
| **Simulador** | `/simulator` | Proyección de ingresos según mix de servicios vendidos |

### Métricas clave que calcula

| Métrica | Fórmula |
|---|---|
| **Tasa BEP por hora** | Total costos mensuales ÷ Horas de capacidad |
| **Margen por servicio** | (Precio - Costo BEP × Horas estimadas) / Precio × 100 |
| **Depreciación mensual** | Valor inicial ÷ (Vida útil en años × 12) |
| **IVA en cotizaciones** | Subtotal × 19% (automático) |

### Stack Técnico

| Tecnología | Uso |
|---|---|
| React 18 + Vite | Framework UI |
| TypeScript | Tipado estático |
| Tailwind CSS | Estilos con tokens de diseño |
| React Router v7 | Enrutamiento |
| Firebase Auth | Autenticación email/Google OAuth |
| Cloud Firestore | Persistencia de datos (un documento por usuario) |
| Recharts | Gráficos de Analytics |
| html2pdf.js | Exportación de cotizaciones a PDF |
| uuid | Generación de IDs únicos |
| GitHub Pages | Hosting |

## 10. GLOSARIO

| Término | Definición |
|---|---|
| **BEP** | Break-Even Point (Punto de Equilibrio): ingreso mínimo para cubrir costos |
| **Tasa BEP/hora** | Total de costos ÷ Horas de capacidad = costo mínimo facturable por hora |
| **Brand Kit** | Conjunto de activos de marca del cliente (logo, colores, fuentes, manual) |
| **BrandForm** | Formulario de onboarding en Kontenda para definir el ADN de la marca |
| **Pilar de contenido** | Categoría temática que organiza el tipo de publicaciones de un cliente |
| **Ronda de revisión** | Una iteración de correcciones sobre una pieza de contenido |
| **ProgressTracker** | Barra visual de 5 etapas que muestra el avance mensual de producción |
| **CLP** | Peso chileno (moneda local) |
| **IVA** | Impuesto al Valor Agregado (19% en Chile) |
| **RUT** | Rol Único Tributario — identificador fiscal chileno |
| **Frame.io** | Plataforma de revisión y entrega de video (integrada en Kontenda vía URL) |
| **Vibe Coding** | Desarrollo de software con asistencia activa de IA (Claude, Gemini, etc.) |
| **Depreciación lineal** | Reducción del valor de un activo en partes iguales durante su vida útil |
